# CodeAlpha_Hangman_Game


A simple text-based Hangman game built in Python, where the player guesses a word one letter at a time.

## Features
- Random word selection from a predefined word list
- Tracks wrong guesses, with a limit of 6
- Displays guessed progress using blanks (e.g. `_ y t h _ n`)
- Option to play multiple rounds

## How to Run : python hangman.py in terminal

## Concepts Used
- `random` : selecting a random word
- `while` : loops main game loop
- `if-else` : logic validating and checking guesses
- Strings and sets : tracking guessed letters and word progress

## Example
Welcome to Hangman!
The word has 6 letters.

Word: _ _ _ _ _ _
Wrong guesses: 0/6
Guess a letter: p
